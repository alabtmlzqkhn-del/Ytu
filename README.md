# fadilenSalim.com

موقع خاص محمي بتسجيل الدخول.

## التشغيل
```bash
pip install -r requirements.txt
python app.py
```

ثم افتح:
http://127.0.0.1:5000

## لوحة الإدارة
بعد تسجيل الدخول كمدير:
http://127.0.0.1:5000/admin

## مهم عند النشر
ضع هذه المتغيرات في إعدادات الاستضافة:
- SECRET_KEY
- ADMIN_EMAIL
- ADMIN_PASSWORD

اسم fadilenSalim.com داخل تصميم الموقع. للحصول على الرابط الحقيقي fadilenSalim.com يجب تسجيل/شراء الدومين إذا كان متاحاً ثم ربطه بالاستضافة.
